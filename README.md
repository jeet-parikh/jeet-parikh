**React · TypeScript · Firebase**

### [PlantVision AI](https://github.com/jeet-parikh/PlantVision-AI)
An iOS app that identifies plant diseases from leaf photos.
Trained on 20,000+ images, with over 90% accuracy and offline
inference using Core ML.

**Swift · TensorFlow · Core ML**  
[App Store](https://apps.apple.com/us/app/plantvision-ai-detect-disease/id1547100846)

### [Kare](https://github.com/jeet-parikh/Kare)

**SwiftUI · Firebase · Cloud Firestore**  
[App Store](https://apps.apple.com/us/app/kare-enabling-independence/id1660828940)

### [DeepDoc](https://github.com/jeet-parikh/DeepDoc)

**Python · FastAPI · LangChain · FAISS · React · Tailwind CSS**
